## 변경

- 월간 열 제목을 상단 메뉴 아래 고정하고 가로 스크롤·집중 보기와 동기화한다.
  이월 잔액을 충전액 왼쪽으로 옮기고 파랑·주황으로 구분한다. 직전 잔액 안내는 숫자만
  표시하며 사용자 합의에 따라 `10,000,000`까지 표시 너비를 검증한다. 서버 금액 상한은 유지한다.
- 금액 입력의 쉼표·커서·붙여넣기를 처리하고 오류 원문을 보존한다. 유효 금액 표시 차이는
  검수/재전송 비교에서 정규화한다. 확정 버튼 근처에 원인·해결 방법·입력 이동을 제공하고,
  초안 저장 복구 성공 때 이전 저장 오류만 해제한다.
- 기존 비재직 일반 인원도 별도 구역에서 필수 이월을 입력하고 `inactive_kept`로 기록한다.
  충전액 0·비재직 상태 유지, 요청 인원/신규 전환 인원 제외, 기존 초안 map·동시성 계약 유지.
- 팀 일반 인원의 재직/비재직/전체 현재 총 잔액 합계와 색상 자동 저장을 추가한다.
  금액을 Python 정수로 합산하여 큰 누적 이관 금액의 SQLite SUM overflow를 피한다.
- 인원 목록·팀 상세·개인 상세에 장부 기준 재직 기간을 최신순으로 표시한다. 시작·종료월 포함,
  진행 중 기간은 KST 현재 월까지 계산하며 비재직 근거 없는 공백은 연결한다. 월간/개별 상태
  변경의 실제 순서를 반영하고 시작 근거 부족·현재 상태 불일치는 미확인, 공용은 적용 제외다.
- 대시보드 재직 표 아래 as_of 전체 표를 제공한다. 과거 미관측·비재직 잔액을 포함하고
  미확인은 안내한다. Excel `팀별`/`팀별 전체` 시트가 같은 cutoff·필터·집계 결과를 사용한다.
- 앱 버전 1.5.0, CHANGELOG·README·사용 가이드·아키텍처·상시 업무 규칙을 갱신한다.
  DB 스키마와 Excel v1/v2 입력 열 계약은 바꾸지 않는다.
