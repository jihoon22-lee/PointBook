## 변경

- 프로필 선택의 DB 조회와 선택 검증에 공통 포인트번호 정규화를 적용한다. 입력 원문,
  현재 프로필/인원 ID/선택 서명 검증과 오래된 선택 거부는 유지한다.
- 입력 단계에서만 유형 생략과 명시를 구분한다. 문자열 메타는 이름 재확인·두 사진 결합에서
  보존되지만 초안·폼·검수 서명에는 포함하지 않는다. 기존 초안은 저장된 값을 그대로 읽는다.
  Gemini 지침도 명시 일반/person, 명시 공용/shared, 유형 표시 없음/빈 문자열로 맞춘다.
  표준 XLSX의 유형 처리 계약은 유지한다.
- ZIP의 실제 행·셀을 먼저 검증하고 XLSX dimension을 실제 내용으로 다시 계산해 읽는다.
  행 안의 열 순서도 검사하여 재계산 과정에서 앞에 배치한 추가 셀이 숨지 않게 한다.
- 따옴표 없는 입력도 20,000자 한도와 CSV 오류 처리를 거친다. 오류 원문과 다음 정상 행은
  보존하며, 초안 한도를 넘는 입력은 기존 저장 오류 안내를 따른다. 전역 CSV 한도는 바꾸지 않는다.
