# v1.7.1 버전·릴리스

## 문제와 범위

v1.7.0 이후 수정 PR #90과 의존성 PR #91이 main에 반영됐지만 앱 버전은 v1.7.0이었다.
사용자가 버전 올림·태그·릴리스를 요청했다. 버그 수정과 의존성 갱신만 포함하므로 v1.7.1로 올린다.

- [#90](https://github.com/jihoon22-lee/PointBook/pull/90) 이후 월 관측 차단을 확정 대상 계정으로 한정
  (기록: `workthrough/2026-10-22-later-observation-shared-scope.md`)
- [#91](https://github.com/jihoon22-lee/PointBook/pull/91) certifi 2026.10.19(PYSEC-2026-4320)

## 변경과 검증

버전 상수·버전 검사·README·CHANGELOG만 바꾼다. 기능 로직·DB 스키마·lockfile은 변경하지 않는다.
운영 환경 파일 없는 worktree와 임시 DB에서 버전 검사, Ruff check/format, mypy와 릴리스 노트 추출을
확인한다. PR 필수 CI 전체 통과 후 squash merge하고 머지 소스에 v1.7.1 태그를 발행한다.
릴리스는 태그 push의 Release workflow가 CHANGELOG 섹션으로 만든다.

## 한계

운영 배포는 이번 요청 범위가 아니며 수행하지 않았다. 운영 반영은 별도 승인 후
`scripts/deploy.sh` 절차로 진행한다. 실제 Gemini API·Win7 Chrome 109·갤럭시 실기 검증은 미실행이다.
