# v1.4.0 운영 전환과 릴리스 문서

운영 적용 뒤에도 CHANGELOG가 릴리스 후보이고 수용 기록이 이전 Gemini 실패·배포 전 상태를
표시하던 부분을 실제 결과로 갱신했다. 앱·DB·배포 스크립트 변경은 없다.

사용자가 실기 검증을 배포 후 직접 수행하도록 명시해 선행 차단 조건을 변경했다. 자동 테스트를
실기 PASS로 바꾸지 않고 사용자 사후 확인으로 남긴다. 운영 DB 사전 백업·복원 예행·이전과
기동·재시작, 기존 모든 컬럼의 행별 일치, 로그인/읽기/Excel, 정기 백업을 확인했다.

런타임 검증 source는 #67의 `59e4b11ead3e4a18574836da4b9c291e30eb9643`, 운영 적용 source는
`1176086318d0b42c84f2914c8759ac0a1263fb90`이며 두 Git tree는 같다. #67 CI는 706 tests/93.58%,
15 E2E와 필수 게이트 전체 통과다. 이 문서 변경은 Dockerfile에 복사되는 경로와 이미지 빌드 입력을
바꾸지 않아 검증된 동일 이미지 bytes를 유지한다. 정확한 최종 태그/이미지/운영 상태는 #58에 연결한다.

문서 diff·링크·Dockerfile 입력 무변경을 확인했다. 공개 증거에 실자료·주소·환경값을 포함하지 않았다.
