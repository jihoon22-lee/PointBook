# v1.4.5 검수 표 너비와 세로 비교

## 문제와 변경

검수 화면의 최대 폭과 이름·비교 버튼의 최소 폭 때문에 오른쪽 열 확인에 가로 이동이
필요했다. 사용자는 화면 폭 확대와 내용별 열 너비 조정을 승인했고, 비교 선택은 새 인원
하위 행으로 옮기지 않고 해당 칸 아래 현재 등록값·이번 입력값을 위아래 두 줄로 요청했다.

- 검수 템플릿만 전체 브라우저 폭을 사용한다. 다른 화면은 기존 기본 컨테이너를 사용한다.
- 열별 너비를 지정하고 포인트번호 8자리·쉼표 금액을 확인할 공간을 확보한다.
  이름 아래 연결 태그를 배치하고 긴 비고와 좁은 화면은 표 내부에서 처리한다.
- 현재/입력 선택 버튼은 해당 필드 아래에 수직으로 배치한다. 선택 강조와 재선택을 유지하며
  한 행의 차이 표시가 해당 열 전체를 과도하게 넓히지 않도록 한다.
- 인원 연결·선택·초안·확정·금액 로직과 Excel 입력 계약은 변경하지 않는다.
  기존 연결 후 위치·가로 스크롤·포커스 복원도 유지한다.

사용자 화면 수정 계약 → #48 R20/R21/R22 → WP08/09 → 본 PR/source SHA/필수 CI.
실제 요청서 사진은 증거·fixture에 넣지 않고 격리 worktree의 합성 자료만 사용한다.

## 실제 검증

Python 3.13/uv.lock, 운영 .env 없는 worktree, 명시적인 임시 DATABASE_PATH를 사용했다.

- 정보 선택·버전 HTTP 회귀 18건 통과(6.29초).
- Ruff check/format, mypy app scripts 통과.
- E2E는 1280/1920 화면에서 표 너비·가로 넘침·8자리 번호·쉼표 금액을 실제 렌더 크기로
  확인하며, 해당 팀 칸의 수직 비교·선택 강조·이름 아래 태그·좁은 화면 위치 복원을 검증한다.
  최종 18건 통과(36.14초). 처음 실행에서 일반 행 높이 115.4px로 기존 110px 기준을 넘은
  것을 확인하고 입력·태그·셀 여백을 조정한 뒤 해당 회귀를 포함해 모두 통과했다.
- 독립 CSS 검토에서 추가 차단 결함 없음. 전체 필수 CI는 PR merge ref 결과로 연결한다.

Win7 Chrome 109·갤럭시 실기 검증은 미실행이다. 운영 초안의 삭제·복원·확정이나 실제 금액
적용은 수행하지 않는다. 릴리스/배포의 실제 결과는 source·CI·이미지 정보와 함께 기록한다.
