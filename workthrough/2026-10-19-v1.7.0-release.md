# v1.7.0 버전·릴리스·운영 반영

## 문제와 범위

v1.6.1 전체 코드 리뷰 후속 수정 PR #84~#88과 의존성 PR #83이 main에 반영됐지만 앱 버전은
v1.6.1이었다. 사용자가 버전 올림·문서 갱신·태그·릴리스·운영 배포를 요청했다. 새 화면 기능과
수정을 포함하므로 v1.7.0으로 올린다.

기능 PR: [#84](https://github.com/jihoon22-lee/PointBook/pull/84) 웹 경계,
[#85](https://github.com/jihoon22-lee/PointBook/pull/85) 관측 순서·팀 삭제 감사,
[#86](https://github.com/jihoon22-lee/PointBook/pull/86) 입력 경계,
[#87](https://github.com/jihoon22-lee/PointBook/pull/87) 화면 사용성,
[#88](https://github.com/jihoon22-lee/PointBook/pull/88) 대시보드 규모 응답,
[#83](https://github.com/jihoon22-lee/PointBook/pull/83) Mako 1.4.2.
기록은 각 PR의 workthrough(2026-10-18·19)에 있다.

## 변경과 검증

버전 상수·버전 검사·README·CHANGELOG·아키텍처 문서만 바꾼다. 기능 로직·DB 스키마·lockfile은
변경하지 않는다. 운영 환경 파일 없는 worktree와 임시 DB에서 버전 검사, Ruff check/format,
mypy와 릴리스 노트 추출을 확인한다. PR 필수 CI 전체 통과 후 squash merge하고 머지 소스에
v1.7.0 태그를 발행한다.

운영 반영은 머지 소스에서 빌드한 이미지 ID를 고정해 합성 환경에서 먼저 확인한 뒤
`scripts/deploy.sh`(이전 이미지 보존 → DB 이전 예행 → 정지 후 백업 → 기동·재시작·백업 대비 장부 대사)로
수행한다. 환경 설정·마운트·포트를 유지하고, 배포 전후 DB 행 내용을 대조하며 실제 월간 입력·확정을
검증 목적으로 수행하지 않는다. 최종 source·CI·이미지 및 운영 확인 결과는 릴리스 노트에 연결한다.

실제 Gemini API·Win7 Chrome 109·갤럭시 전체 실기 검증은 미실행이며 합성 자동 검증과 구분한다.
