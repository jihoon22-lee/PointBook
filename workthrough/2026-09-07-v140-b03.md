# v1.4.0 B03 · 당시 정보·정정·관측 기준 집계

WP06 #54, WP07 #55 / R01, R04, R06, R12, R14–R19, R24, R26.

기본 정보 편집이 최신 금액과 과거 소속을 함께 덮던 경로를 분리했다. 월별 기록은 당시
프로필·비고·출처·버전을 고정하고, 기존 장부는 `master_at_migration` 참고 출처와 원래
관측 시각 NULL을 남긴다. `d14a06000001`은 기존 금액을 바꾸지 않고 baseline revision을
보존한다. 원래 작성자·시각을 추정하지 않는다.

현재 프로필, 과거 정정·빈 월 삽입, 현재 잔액 보정은 서명한 전후 계획을 승인한다.
SQLite 쓰기 잠금 안에서 계획·장부 버전을 재검증하고 사전 백업 뒤 변경과 감사 원장을
같이 저장한다. 같은 작업·payload는 한 번 반영하고 다른 payload·오래된 탭은 거부한다.
과거 total 정정은 다음 실제 월간 기록의 usage에 반영하되 이후 입력 carry/amount와 중간
명시적 관측을 보존한다. 초기·현재 잔액 관측은 월 전체를 마감하거나 월간 충전을 만들지 않는다.
이월 입력은 계산된 총액 MAX_TOTAL까지 허용하고 충전 후 합계도 같은 상한으로 검증한다.

`observations.py`와 `stats.Report`가 당시 유형·팀, 월간 활동, 해당 월 관측/선택 월까지 마지막
관측, 미확인 과거와 정정판 cutoff를 공유한다. 비재직 보유값을 누락하거나 없는 관측을 0원으로
만들지 않는다. 감사·revision·보정은 UPDATE/DELETE trigger로 보호한다. 읽기 전용 정합성
검사와 계산 필드 복구는 원문·미확인 정보 보존, 별도 사전 사본, 승인·재검사·rollback을 갖춘다.
