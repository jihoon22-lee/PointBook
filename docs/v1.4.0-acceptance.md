## 최종 수용의 미실행·제한

- 실제 Gemini `gemini-3.6-flash`는 승인된 기존 키와 **합성 사진만** 사용했다. 모델 목록에서
  접근 가능함을 확인했지만 인식 세 번은 공급자 `503 UNAVAILABLE`/과부하 응답이었다.
  안전한 오류 경계는 확인했으며 **실제 성공 인식은 미확인**이다. 모델·키를 자동 변경하지 않았다.
  최신 모델의 폐기된 sampling parameter는 제거했다. [공식 변경 안내](https://ai.google.dev/gemini-api/docs/changelog).
- Win7 Chrome109·Android 실제 장치 수용은 미실행이다. 현재 연결 환경에서 해당 테스트 장치나
  BrowserStack 계정을 확보하지 못했다. 초기 요청한 실기 환경/검증 결과가 필요하다.
  구형 Chromium·390px·IE User-Agent 안내 검증으로 이를 PASS 처리하지 않는다.
- 운영 자료 사전 백업·격리 사본 이전/행별 대사·정확한 후보 이미지·실제 프록시 읽기 결과는
  #58에 실행 시점·소스·이미지와 함께 추가한다. 운영 원본 이전·정기 실행 설치·최종 태그/릴리스/
  배포는 필수 수용을 충족한 뒤 수행한다.

따라서 이 문서 작성이나 B04 CI 성공만으로 #47/#48/#58 또는 마일스톤을 종료하지 않는다.


## 실기 피드백 반영: 기존 업무 양식과 집계 복구

기존 Excel의 월별 충전액 0원은 일반 인원의 비재직, 지급액 있음은 재직이다. 일괄 이관을
이력 미확인의 근거로 취급했던 구현을 정정한다. 이름·번호·팀·계급은 인원 마스터 한 곳에서
관리하며 과거 월/집계/Excel에도 현재값을 사용한다. 월별 별도 인원 정보 정정과 반복 출처/
정정판 표시를 제거하고, 개인 월별표의 5열 및 대시보드 재직·비재직 전환 인원을 복구한다.

R01/R14/R16/R18/R21/R23, S04/S05/S10/S11의 관련 기준은 이 정정과 #48의 최신 명세를 따른다.
`tests/test_legacy_status.py`는 이전 형태의 원본 정정판, 재직/비재직/복귀/공백, 금액 정정, 공용
제외, 현재 인원 정보/팀 필터, HTML/Excel/월별 집계 일치를 검증한다. 일반 조회 양식은 기존
`e2e/tests/test_flow.py`의 개인 이력 흐름에서 확인한다. 최종 실행·운영/실기 결과는 #58을 따른다.
