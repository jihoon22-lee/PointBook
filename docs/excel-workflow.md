# 표준 Excel 입력과 보고서

기본 월간 입력 양식은 포인트번호 없는 표준 요청서 v2이며 기존 v1 업로드도 지원한다. 기존 2024-05~2026-08 누적 장부
이관기는 별도 고정 형식을 유지하며 표준 업로더의 파서로 재활용하지 않는다.

## 입력 양식

월간 처리에서 선택 월의 템플릿을 내려받는다. `요청서` 시트 A1은 `PointBook 월간 요청서`,
B1은 양식 버전 `2`, B2는 `YYYY-MM` 처리 월이다. 선택한 웹 처리 월과 일치해야 한다.
4행 제목을 유지하고 5행부터 아래 열을 입력한다.

| 열 | 값 |
|---|---|
| A 순번 | 선택, 업무 식별에 사용하지 않음 |
| B 계정 구분 | `person`/`shared` 또는 일반/공용 |
| C 팀 | 공용·팀 미배정은 빈칸 가능 |
| D 이름 | 필수, 이름 중복 허용 |
| E 계급 | 선택 |
| F 충전액 | 필수 0 이상 정수, 0과 빈칸 구분 |
| G 개인번호 | 문자열, 모르면 빈칸으로 두고 웹 검수에서 확인. 중복 허용 |
| H 비고 | 선택, 줄바꿈·빈 줄을 포함한 원문 보존 |
| I 이월 잔액 | 모르면 빈칸. 자동 연결은 유지하며 수동 연결·연결 변경 시 다시 입력 |

소방서에서 외부 포인트번호를 조사해 넣을 필요는 없다. 업로드 뒤 이름·개인번호·계정 유형이
모두 정확히 일치하는 기존 계정이 하나면 자동 연결한다. 개인번호가 빈 공용계정은 자동 연결하지
않는다. 자동 연결은 포인트번호만 보완하며 요청서의 팀·계급·충전액·비고·원문·이월을 유지한다.
같은 이름·개인번호의 계정이 여러 개면 관리자가 후보를 직접 선택한다. 자동 연결 결과도
수동으로 바꿀 수 있다. 이름 또는 개인번호로 후보를 찾을 수 있으며 후보가 없으면 입력을
확인하고 재검수한다.

수동 연결은 요청서 정보를 덮어쓰지 않는다. 이름·개인번호·팀·계급·유형이 현재 인원 정보와
다르면 현재 값과 이번 입력값을 해당 칸 아래 위아래 두 줄로 보고 항목별로 선택한다. 자동 연결된 행에도 같은
차이 확인을 적용한다. 선택 결과는 초안에 보존하고 확정 때 현재 인원 정보에 반영한다.
이번 입력의 빈 팀·계급을 명시적으로 선택하면 현재 값을 비울 수 있다. 유형 변경은 인원
편집에서 처리하며 월간 검수에서는 기존 유형을 선택할 수 있다. 충전액·비고·원문은 유지하고
수동 연결 시 이월 잔액은 다시 입력한다. 자동 연결 후에도 연결 대상이나 이름·개인번호를
바꾸면 기존 이월을 다시 입력한다. 신규 인원의 번호는 외부 시스템에서 발급받아 웹 검수에
입력한다. 신규를 선택해도 미발급 상태는 초안으로 보존하며 임의 번호로 확정하지 않는다.
이미 등록된 포인트번호를 신규로 지정하면 확정할 수 없다.

검수 화면은 이름·개인번호·포인트번호·팀·계급·충전액·이월 잔액·비고·유형 순서로 표시하지만,
Excel v2의 위 9열 순서는 바꾸지 않는다.

기존 v1은 B1=`1`, H=포인트번호, I=비고, J=이월 잔액인 10열 양식을 그대로 지원한다.
번호는 텍스트로 입력해 선행 0을 보존한다. 보고서나 임의 엑셀을 표준 파일로 업로드하지 않는다.

번호 없는 붙여넣기는 `팀 / 이름 / 계급 / 충전액 / 개인번호` 제목 행을 포함한다.
v2 전체 9열도 제목과 함께 붙여넣을 수 있다. 기존 번호 포함 입력도 유지한다.

전체가 빈 행만 건너뛴다. 일부 셀이 비어 있거나 잘못된 행도 시트/행/셀 위치·원문을
검수에 남긴다. 숫자 셀로 저장된 식별자는 선행 0을 추정하지 않는다. 수식 셀은 실제 값으로
고쳐 재검수해야 하며 캐시된 계산값을 사용하거나 수식을 평가하지 않는다.

업로드 → 원문 검수 → 서버 초안 → 전체 인원 대사·이월 입력 → 최종 확정 순서다.
파일을 업로드했다고 장부에 바로 적용하지 않는다. Excel은 외부 AI로 전송하지 않는다.
비고는 검수·초안 복구·금액 수정·보고서 다운로드까지 여러 줄을 유지한다.
Windows의 CRLF/CR 줄바꿈은 LF로 통일하며, 줄 내용과 빈 줄은 제거하지 않는다.

## 한도와 파일 경계

- `.xlsx`만 지원한다. `.xls`, `.xlsm`, 매크로·ActiveX·외부 링크 관계는 거부한다.
- 압축 10MB, 해제 합계 30MB, 항목 하나 10MB, 최대 200개 항목·압축률 200배다.
- 요청서/안내 최대 2시트, 입력 2,000명·v2 9열(v1 10열)이다. 중복 ZIP 항목·뒤섞인 행/셀 위치를 거부한다.
- XML은 defusedxml로 읽으며 외부 엔티티를 확장하지 않는다. 처리 예산은 8초, 동시에
  최대 2개를 실행한다. 취소/timeout 뒤에도 실제 작업 종료까지 슬롯을 유지한다.
- 서버 초안은 최대 16MB, 개별 원문 셀은 20,000자 한도다. 업무 확정 값은 별도의
  이름/식별자/비고/금액 도메인 검증을 통과해야 한다.
- 원본 파일은 임시 메모리에서 처리하며 영구 보관하지 않는다. 입력/다운로드는 인증과
  `no-store`, 상태 변경은 CSRF 검증을 적용한다.

## 보고서 다운로드

대시보드·개인 상세·팀 상세·공용 계정 보고서에서 조회한 조건으로 다운로드한다.
월/일반·공용/팀·개인/잔액 범위/정렬을 공유한다. 화면이 조회한 변경 이력 기준 번호를
다운로드 링크에도 고정해 이후 금액 정정으로 결과가 섞이지 않게 한다. 이름·포인트번호·
개인번호·팀·계급은 과거 월을 조회하더라도 현재 인원 정보를 사용한다.

- **요약**: 기준 월·잔액 범위·분류·필터·변경 이력 기준 번호·생성 시각과 처리/잔액 확인/미확인 인원 수·합계.
- **인원**: 현재 이름·식별자·팀·계급과 기록의 상태, 월간 금액·선택 범위 잔액·관측 월·월간 및 잔액 비고.
- **분류 미확인**: 기록의 계정 유형을 선택 필터로 분류하지 못한 값을 별도로 표시.
- **팀별**: 월간 금액과 잔액을 현재 팀으로 집계.

처리 인원은 해당 월 일반 재직자와 실제 비재직 전환 인원이다. 개별 등록·복귀 후
월간 요청서에서 빠져 비재직으로 전환한 인원도 포함하며 기존 비재직자·공용계정은 제외한다.
기존 Excel 장부와 비어 있던 과거 월에 추가한 일반 인원 기록은 충전액 0원이면 비재직,
지급액이 있으면 재직이다. 공용계정은 항상 재직이며 과거 월 추가로 현재 재직 상태를 바꾸지 않는다.

월간 기록이 없으면 사용 0원으로 만들지 않으며 관측 없는 잔액은 미확인으로 남긴다.
이름·비고 등 텍스트는 `=`, `+`, `-`, `@`로 시작해도 문자열 셀로 쓴다. XML에 넣을 수
없는 제어 문자는 `\u0001`처럼 표시한다. 16자리 이상 정수 합계도 Excel 자릿수 손실을 막기
위해 문자열로 보존한다. 최대 10,000행이며 초과하면 범위를 줄여야 한다. 일부 행만 조용히
잘라 내보내지 않는다.

보고서는 입력용 요청서가 아니므로 다시 업로드할 수 없다. 실제 보고서에는 개인정보가
포함될 수 있어 공개 저장소·CI artifact에 저장하지 않는다.
